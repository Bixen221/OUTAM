# ENA-2025 🌐

Un site web personnel développé avec HTML, CSS et JavaScript.

## 📋 Description

ENA-2025 est un projet web personnel conçu et développé from scratch. Il présente mes compétences en développement front-end à travers une interface moderne et responsive.

## 🚀 Technologies utilisées

- **HTML5** — Structure des pages
- **CSS3** — Mise en forme et design
- **JavaScript** — Interactivité et dynamisme

## 📁 Structure du projet

```
ENA-2025/
├── index.html        # Page principale
├── css/
│   └── style.css     # Feuilles de style
├── js/
│   └── script.js     # Scripts JavaScript
└── README.md         # Documentation
```

## ✨ Fonctionnalités

- Design responsive (mobile, tablette, desktop)
- Interface moderne et intuitive
- Navigation fluide

## 🛠️ Installation

1. Clone le repository :
```bash
git clone git@github.com:Bixen221/ENA-2025.git
```

2. Ouvre le fichier `index.html` dans ton navigateur
